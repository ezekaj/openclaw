# ChatGPT Image Generation Workflow

## Correct Process for Getting Clean Images

When generating images in ChatGPT:

1. **Generate image** in ChatGPT
2. **Click on the image** to view it full-size/focused
3. **Take screenshot** of just the image
4. **Crop to image dimensions** - remove all UI/browser chrome
5. **Save** the clean, cropped image

## Why This Matters
- Cleaner images for ads/portfolio
- No browser UI clutter
- Professional presentation
- Perfect dimensions for upload

## Example
❌ **Wrong:** Screenshot entire page with browser UI
✅ **Right:** Click image → Screenshot → Crop to image only
